Checks whether the graph contains a cycle. 

This function performs a topological sort on all nodes and compares the result size with the number of nodes in the graph.

If the sizes differ, it means that at least one cycle exists in the dependency graph (i.\+e., some nodes cannot be topologically ordered).

\begin{DoxyWarning}{Warning}
This check is purely informational. It is NOT used as a strict execution guard in the current update pipeline, since the graph evaluation system executes nodes in a single-\/pass topologically ordered schedule and does not rely on reactive or recursive propagation. Therefore, cycles will not cause infinite execution loops, but they may still indicate an invalid or non-\/deterministic graph structure.
\end{DoxyWarning}
\begin{DoxyReturn}{Returns}
true if a cycle is detected, false otherwise. 
\end{DoxyReturn}
