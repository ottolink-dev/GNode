GNode supports three update execution modes depending on whether evaluation is synchronous, deferred/debounced on a background thread, or parallelized across independent DAG branches.

\hypertarget{md_docs_2update__process_autotoc_md43}{}\doxysection{\texorpdfstring{1. Sequential Update ({\ttfamily Graph\+::update})}{1. Sequential Update ({\ttfamily Graph\+::update})}}\label{md_docs_2update__process_autotoc_md43}
In sequential mode, {\ttfamily Graph\+::update()} executes synchronously on the calling thread\+:


\begin{DoxyEnumerate}
\item {\bfseries{Validation \& Ordering}}\+: Validates requested node IDs and computes a topological order ({\ttfamily topological\+\_\+sort} for full updates, or {\ttfamily get\+\_\+nodes\+\_\+to\+\_\+update} for selective updates). Throws {\ttfamily std\+::runtime\+\_\+error} if a cycle is detected.
\item {\bfseries{Sequential Evaluation}}\+: Iterates through the sorted nodes one by one, checking {\ttfamily cancel\+\_\+update\+\_\+callback(nid)} before each {\ttfamily node-\/\texorpdfstring{$>$}{>}update()}.
\item {\bfseries{Completion}}\+: Fires {\ttfamily graph-\/\texorpdfstring{$>$}{>}update\+\_\+finished()} once all scheduled nodes complete.
\end{DoxyEnumerate}

\hypertarget{md_docs_2update__process_autotoc_md45}{}\doxysection{\texorpdfstring{2. Deferred Update with {\ttfamily Graph\+Worker}}{2. Deferred Update with {\ttfamily Graph\+Worker}}}\label{md_docs_2update__process_autotoc_md45}
{\ttfamily Graph\+Worker} ({\ttfamily \doxylink{graph__worker_8hpp}{GNode/include/gnode/graph\+\_\+worker.\+hpp}}, {\ttfamily GNode/src/graph\+\_\+worker.\+cpp}) orchestrates non-\/blocking, debounced background updates\+:


\begin{DoxyEnumerate}
\item {\bfseries{Request \& Coalescing}}\+: {\ttfamily Graph\+Worker\+::request(graph, node\+\_\+ids)} acquires {\ttfamily state\+\_\+mutex}, coalesces dirty node IDs into the pending {\ttfamily Job} for that graph, and sets {\ttfamily cancelled = true} if that graph is currently mid-\/pass.
\item {\bfseries{Pre-\/\+Compute Snapshot}}\+: On the caller thread, {\ttfamily start\+\_\+next()} calls {\ttfamily on\+\_\+pre\+\_\+async\+\_\+compute()} on all planned nodes before spawning the background {\ttfamily std\+::thread}.
\item {\bfseries{Background Execution \& Resumption}}\+: The background thread runs {\ttfamily graph-\/\texorpdfstring{$>$}{>}execute\+\_\+parallel(planned)}. When it finishes (or is cancelled), it posts {\ttfamily end\+\_\+pass()} back to the caller thread via {\ttfamily post\+\_\+to\+\_\+caller}\+:
\begin{DoxyItemize}
\item {\bfseries{Error}}\+: Drops only the failing graph\textquotesingle{}s queued jobs and invokes {\ttfamily failed(error)}.
\item {\bfseries{Preempted / Cancelled}}\+: Calls {\ttfamily on\+\_\+async\+\_\+compute\+\_\+cancelled()} on unstarted nodes and re-\/queues them with any newly requested nodes.
\item {\bfseries{Completed}}\+: Fires {\ttfamily graph-\/\texorpdfstring{$>$}{>}update\+\_\+finished()}.
\end{DoxyItemize}
\item {\bfseries{Synchronous Flush}}\+: {\ttfamily Graph\+Worker\+::finish()} stops background work and drains remaining queued jobs synchronously, cleaning up {\ttfamily is\+\_\+finishing} and {\ttfamily cancel\+\_\+update\+\_\+callback} even if a node throws.
\end{DoxyEnumerate}

\hypertarget{md_docs_2update__process_autotoc_md47}{}\doxysection{\texorpdfstring{3. Async Update with Parallel Graph Branch Execution ({\ttfamily Graph\+::execute\+\_\+parallel})}{3. Async Update with Parallel Graph Branch Execution ({\ttfamily Graph\+::execute\+\_\+parallel})}}\label{md_docs_2update__process_autotoc_md47}
{\ttfamily Graph\+::execute\+\_\+parallel(dirty\+\_\+node\+\_\+ids, num\+\_\+threads)} ({\ttfamily GNode/src/graph.\+cpp}) parallelizes independent DAG branches using a {\ttfamily Thread\+Pool} ({\ttfamily \doxylink{thread__pool_8hpp}{GNode/include/gnode/thread\+\_\+pool.\+hpp}})\+:


\begin{DoxyEnumerate}
\item {\bfseries{Cycle Check \& In-\/\+Degree Graph}}\+: Runs {\ttfamily topological\+\_\+sort(dirty\+\_\+node\+\_\+ids)} to verify acyclicity, then builds atomic {\ttfamily in\+\_\+degree\mbox{[}nid\mbox{]}} counters and {\ttfamily dirty\+\_\+dw\mbox{[}nid\mbox{]}} adjacency lists restricted to the dirty set.
\item {\bfseries{Root Scheduling}}\+: All nodes with {\ttfamily in\+\_\+degree == 0} are enqueued immediately via {\ttfamily Thread\+Pool\+::enqueue\+\_\+detached()}.
\item {\bfseries{Dynamic Fan-\/\+Out / Fan-\/\+In}}\+: When a node finishes {\ttfamily node-\/\texorpdfstring{$>$}{>}update()}, it atomically decrements {\ttfamily in\+\_\+degree\mbox{[}dw\+\_\+id\mbox{]}} for each downstream dirty node. Whichever upstream branch decrements {\ttfamily in\+\_\+degree} from {\ttfamily 1} to {\ttfamily 0} enqueues {\ttfamily dw\+\_\+id}.
\item {\bfseries{Cancellation \& Error Handling}}\+:
\begin{DoxyItemize}
\item Before executing or enqueuing, {\ttfamily cancelled.\+load()} and {\ttfamily cancel\+\_\+update\+\_\+callback(nid)} are checked.
\item If any node throws, the first exception is captured, {\ttfamily cancelled} is set to {\ttfamily true}, {\ttfamily sync\+\_\+cv} is notified, {\ttfamily pool.\+stop\+\_\+and\+\_\+join()} waits for active workers, and the exception is rethrown.
\end{DoxyItemize}
\end{DoxyEnumerate}
