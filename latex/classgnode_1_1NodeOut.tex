class gnode\+::\+Node\+Out$<$ T $>$}
Represents an output boundary slot inside a subgraph. 

Inside the child graph, \doxylink{classgnode_1_1NodeOut}{Node\+Out} acts as a data sink receiving an IN port. When the child graph finishes evaluating, the parent \doxylink{classgnode_1_1SubGraphNode}{Sub\+Graph\+Node} reads from this node and pushes results to its external output ports.
