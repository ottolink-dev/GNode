Detailed Description

template<typename... Args>
class gnode::Event< Args >

Thread-safe publisher-subscriber event stream.

Allows multiple callbacks to subscribe and receive notifications of new values/signals. It can be notified from another thread than the one that subscribes: once a connection is disconnected, its callback is not called anymore (the disconnection waits for a notification in progress).

Template Parameters
ArgsArgument types passed to subscribers when notified.
