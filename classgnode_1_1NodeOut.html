Detailed Description

template<typename T>
class gnode::NodeOut< T >

Represents an output boundary slot inside a subgraph.

Inside the child graph, NodeOut acts as a data sink receiving an IN port. When the child graph finishes evaluating, the parent SubGraphNode reads from this node and pushes results to its external output ports.
