◆ request()

bool gnode::GraphWorker::request ( Graph &  graph,
const std::vector< std::string > *  p_node_ids = nullptr 
)

Queues the specified nodes and their downstream dependencies, or the whole graph if p_node_ids is null.

Cancels any update of that graph in progress: it will resume with what was left plus the newly requested nodes. Never blocks.

Parameters
graphThe graph to update.
p_node_idsOptional subset of dirty node IDs. If null, the entire graph is scheduled.
Returns
true if the job was queued/accepted, false if background updates are disabled and the caller should update synchronously.
